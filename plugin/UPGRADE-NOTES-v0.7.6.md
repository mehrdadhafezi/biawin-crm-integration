# Upgrade Notes v0.7.6

- داشبورد کاربران غیرمدیر اکنون فقط مشتریان/پرونده‌های قابل دسترسی همان کاربر را شمارش می‌کند؛ برای کارشناس تماس عادی یعنی فقط پروفایل‌های دارای Assignment فعال به همان کارشناس.
- آمار صفحه مشتریان نیز بر اساس همان دامنه دسترسی محاسبه می‌شود و دیگر اعداد کل سامانه را به کارشناس عادی نشان نمی‌دهد.
- N+1 query شماره اصلی در لیست مشتریان حذف شد و شماره اصلی در Query اصلی لیست دریافت می‌شود.
- جست‌وجوی شماره موبایل از تطبیق دقیق روی normalized_phone استفاده می‌کند تا از index استفاده شود.
- داشبورد 20 ثانیه cache کوتاه‌مدت per-user دارد تا بار Queryهای همزمان کاهش یابد.
- گزارش جامع مشتریان در صفحه گزارش‌ها اضافه شد: اولین تاریخ تخصیص، اولین کارشناس، کارشناس فعلی، آخرین اقدام و زمان آخرین اقدام.
- خروجی واقعی XLSX به صورت streaming/batched اضافه شد تا همه مشتریان را بدون Load کامل در حافظه دانلود کند.
- خروجی CSV نیز batch/streaming شد.
- روی داشبورد مدیر لینک مستقیم «گزارش جامع مشتریان» و دانلود Excel اضافه شد.
- indexهای ترکیبی برای customers, assignments, invoices, phones, interactions, complaints, financial_cases, service_cases, refunds و activities اضافه شدند.
