# Biawin CRM v0.7.0

- پنل مدیریتی یکپارچه به فرانت پرتال منتقل شد.
- منوی نقش‌محور برای مدیران، سرپرستان و کارشناسان تخصصی اضافه شد.
- صفحات تخصیص، ایمپورت، مالی، شکایت، خدمات، واحدها، عودت، گزارش، کاربران، ممیزی و تنظیمات در پرتال قابل استفاده‌اند.
- متن افشای نام کاربری/رمز پیش‌فرض از صفحه ورود حذف شد.
- UI صفحه ورود و پوسته اصلی پرتال بازطراحی شد.
- نقش مدیر پرتال، سرپرستان مالی/شکایت/عودت اضافه شد.
- کاربران تخصصی اولیه و یک کارشناس اولیه برای هر واحد خدمات Seed می‌شوند.
- Redirect فرم‌های مدیریتی در حالت فرانت به خود پرتال برمی‌گردد.
