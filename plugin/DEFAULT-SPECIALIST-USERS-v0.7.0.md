# کاربران تخصصی اولیه

این حساب‌ها فقط برای آماده بودن گردش کار ساخته می‌شوند و مدیر می‌تواند از بخش «کاربران و دسترسی‌ها» رمز، وضعیت یا حساب‌ها را تغییر دهد.

- financial_supervisor — سرپرست تأیید مالی
- financial_agent — کارشناس تأیید مالی
- complaint_supervisor — سرپرست شکایات
- complaint_agent — کارشناس شکایات
- refund_supervisor — سرپرست عودت وجه
- refund_agent — کارشناس عودت وجه
- برای هر واحد خدمات فعال نیز یک کاربر `agent-<unit-key>` به‌عنوان کارشناس اولیه ساخته می‌شود.

رمز اولیه حساب‌هایی که تازه ساخته می‌شوند: `[رمز پیش‌فرض قدیمی — از v0.8.63.0 حذف شد؛ این حساب‌ها دیگر خودکار ساخته نمی‌شوند]`
این رمز در ارتقاهای بعدی خودکار ریست نمی‌شود.
