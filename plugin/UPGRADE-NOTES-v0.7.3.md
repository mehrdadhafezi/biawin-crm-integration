# Upgrade notes v0.7.3

- Customer profile tab bar is now persistently sticky below the global CRM header.
- Profile anchor targets use scroll margin so sections are not hidden beneath sticky navigation.
- Collapsed desktop sidebar has been rebuilt as a clean icon rail with no horizontal scrollbar.
- Sidebar scrollbars are visually hidden while vertical scrolling remains available when viewport height requires it.
- Every collapsed navigation icon exposes a readable hover/focus tooltip and accessible title/aria-label.
- Sidebar active state is clearer and collapse control no longer floats awkwardly over the menu.
- Portal navigation symbols were made more recognizable.
