# Upgrade Notes - v0.8.24

- Adds `CRM بیاوین > بک‌آپ و بازگردانی` for complete CRM table backups and one-click restore from the portal.
- Import final commit now has a checked-by-default option to create a full backup before changing data.
- Financially unapproved invoice cleanup also has a checked-by-default backup option before real execution.
- Large import batches are increased to reduce upload/import time on large Excel files.
- CustomerID preview statistics now support `C000001` formatted identifiers.
